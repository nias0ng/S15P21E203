## 1. 구현한 것

### 수정 1 — SIM_FRAG : 점 교란 → 선(파면) 교란 ✅ 지시대로

```glsl
uniform vec2 uAmbDir;   // 파면 법선
uniform float uAmbLen;  // 파면 길이
...
vec2 rel = vUv - uAmb.xy;
float across = dot(rel, uAmbDir);
float along  = dot(rel, vec2(-uAmbDir.y, uAmbDir.x));
float fa = across / max(uAmb.z, 1e-4);
float fl = along / max(uAmbLen, 1e-4);
h.x += exp(-fa * fa) * exp(-fl * fl * fl * fl) * uAmb.w;
```

- 법선 방향 가우시안 · 파면 방향 4제곱 (가운데 평평, 끝만 떨어짐)
- 라플라시안 / 감쇠 / 스펀지 / bowGrip / 항적 z채널 — 한 줄도 건드리지 않음

### 수정 2 — JS 교란 생성 규칙 ✅ (위치 규칙 1개만 수정, 아래 3장 참고)

| 위치 | 진행 반대쪽 가장자리 | 방향·수직 오프셋 규칙 그대로, **거리만 축소** |

### 수정 3 — 잔물결 대역 추가 ✅ 지시대로

- `swellH` : `+ uRippleA * sin(dot(p, vec2(0.36,-0.93)) * 1.14 - 1.87 * uTime)`
- `swellG` : 대응 미분항 `c3 * 1.14 * vec2(0.36,-0.93)` 함께 추가
- `SW` 상수에 `d3 / k3 / w3` 추가
- `swellCPU(x, z, t, a, r)` 로 시그니처 확장, 부력 호출부에 `ripA` 전달
  → GPU 수면과 CPU 부력이 완전히 같은 식. 배가 잠기거나 뜨지 않음
- `uRippleA` 를 수면·격자 3단 전부에 매 프레임 갱신

### Tweaks 패널 ✅ 7개 신규

- 수면 : `ambInterval` 0.1~1.5 / `ambLength` 8~50 / `ripple` 0~0.1
- 선 : `lineContrast` 0~1(1) / `iriAmount` 0~1(0.55) / `glintAmount` 0~1(0.8) / `glintScatter` 4~40(18)

1차에서 누락됐던 4개는 **기능 자체가 없었으므로 기능과 함께** 새로 구현했습니다.

## 2. 지시와 다르게 한 것 (1건)

### 파면 발생 거리 : 0.34~0.46 → 0.22~0.28 uv

지시대로 0.34~0.46 에 낳으면 **태어나는 순간 흡수층에 먹힙니다.**

- 스펀지 : `smoothstep(0.58, 1.0, max(d.x, d.y))`, 여기서 `d = |uv-0.5| * 2`
- 즉 중심에서 uv 0.29 를 넘으면 감쇠 시작. 0.46 지점은 계수 0.93 → **스텝당 30% 삭감**
- 그래서 `ambEdge: 0.28` 을 두고 `r = ambEdge * (0.78~1.0)`, 최종 오프셋 길이도 0.28 로 클램프

방향과 "한쪽에서 밀려온다"는 성질은 그대로지만, **조주 거리가 짧아졌습니다.**
검증 6번이 약하게 보이면 다음 수순은 스펀지 시작점을 `0.58 → 0.72` 로 밀고 `ambEdge` 를 0.34 로 올리는 것입니다. (스펀지 수정은 금지 항목이라 이번엔 손대지 않았습니다)

## 4. 작업 중 잡은 버그 (지시 외)

`atan(vGrad.y, vGrad.x)` — GLSL ES 에서 두 인자가 모두 0 이면 **정의되지 않음**.
정지 상태의 원경은 `vGrad` 가 정확히 (0,0) 이라 GPU 에 따라 NaN 이 나오고,
`NaN * 0.0 = NaN` 이므로 `uIriAmt * vSteep` 이 0 인 프래그먼트까지 색이 오염되어
격자 전체가 검게 되거나 사라질 수 있었습니다. → `vGrad.x + 1e-6` 으로 가드.

## 5. 예상되는 다음 논점

- **파면의 기하 변위가 작습니다.** `amb 0.22 × height 0.35 ≈ 월드 0.077`.
  실제 융기로는 거의 안 보이고, `vSteep × crest 1.6` 이 만드는 **선의 짙어짐**으로 읽힙니다.
  등고선 표현으로는 의도에 맞지만, 융기 자체를 보고 싶으면 `sim.height` 를 올려야 합니다.
- **lineContrast 1 에서 격자 평균 톤이 밝아집니다.** 마루가 배경 쪽으로 빠지는 폭이 골이 먹으로 가는 폭보다 지각적으로 크기 때문입니다. 물이 옅어 보이면 `lineContrast` 를 0.6 근처로.
