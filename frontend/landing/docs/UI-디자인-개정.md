## 1. 팔레트 — 레퍼런스와 저녁의 접점

레퍼런스 팔레트(왼쪽)와 이 프로젝트에서의 쓰임(오른쪽).

| 레퍼런스 | 값 | 여기서는 |
|---|---|---|
| IVORY | `#F9F6EF` | **표면 바탕** — 카드 · 검색창 · 미니맵 판 |
| BONE | `#E8E1D6` | 표면의 보조 면 · 구분 띠 |
| STONE GRAY | `#C9C4BB` | **얇은 선** · 비활성 글자 |
| SAGE | `#7F8A7A` | 보조 강조 (지도의 지형 · 안 쓰는 상태) |
| AGED BRONZE | `#A68F5B` | ⭐ **주 강조** — 저녁 하늘과 가장 잘 맞는다 (버튼 · 현재 위치 · 밑줄) |
| CHARCOAL | `#2F2F32` | **표면 위 글자** |
| SEA SHIMMER | `#A7C8DB` | 물빛 강조 — 항로 · 반짝임 · 포커스 링 |

⚠⚠ **`--pb-ink` 와 표면 위 글자는 다른 것이다.** 전자는 *화면 위에 바로 앉는 글자*라
시간대를 타고(저녁 `#FFF4EC`), 후자는 *자기 바탕이 있는 표면 위*라 언제나 CHARCOAL 이다.
v0.44.0 에서 이걸 안 갈라서 **저녁에 카드 제목이 통째로 사라졌다** (불변식 25).

### 토큰 (index.html `<style>` 의 `:root`)

```
--pb-surface        표면 바탕      IVORY        ← 시간대를 타지 않는다
--pb-surface-2      표면 보조      BONE
--pb-surface-glass  반투명 표면    IVORY 88%
--pb-line-soft      얇은 선        STONE GRAY
--pb-on-surface     표면 위 글자    CHARCOAL
--pb-on-surface-2   표면 위 보조    CHARCOAL 62%
--pb-accent         주 강조        AGED BRONZE
--pb-sage           보조           SAGE
--pb-shimmer        물빛           SEA SHIMMER
--pb-lift           표면 그림자     바다 위에 뜬 종이
```

⚠⚠ **`--pb-paper` 를 표면에 쓰지 않는다.** 그 이름은 이미 **화면 바탕**이고 `data-time` 이
저녁에 `#5E5670` 로 바꾼다 — 표면에 쓰면 종이가 남보라가 된다. 표면은 `--pb-surface` 쪽이다.
⚠ 기존 `--pb-glass` (시간대를 타는 어두운 유리)는 남긴다 — 바다 위에 **어둡게** 얹혀야 하는 자리가 있다.

## 2. 폰트

| 무엇 | 폰트 | 비고 |
|---|---|---|
| **DOM UI 전부** | **Noto Serif KR** 400 / 600 | 2026-09-12 변경 (Pretendard → ) |
| **수면 타이포** | Cormorant Garamond 500 | ⚠⚠ **그대로 둔다** (사용자 명시) |

⚠⚠ `title.js` 는 3D 수면에 글자를 그리는 층이고 **영문 대문자 서브셋**만 받는다
(`index.html` 의 `text=ABCDEF…`). 그 링크와 `title.js` 를 건드리지 않는다.
⚠ 한글 세리프는 무겁다 — Google Fonts 의 `unicode-range` 자동 서브셋에 맡기고 `display=swap` 을 준다.
⚠ **넓은 자간의 작은 대문자**(레퍼런스의 `TRAVEL SERVICE`)는 폰트가 아니라 **스타일**이다 :
`font-size:10~11px · letter-spacing:0.18~0.22em · font-weight:600`. 라벨류에 쓴다.

### 4단계에서 나온 것 — 다음 단계가 알아야 할 셋

1. **해도는 SVG 다** (미니맵은 캔버스 비트맵 다섯 층). 전체 화면에서는 구운 그림이 층당 33MB 이고
   확대하면 뭉갠다. 격자인 두 층(안개 · 갈 수 있는 바다)만 **작은 그림 한 장씩**으로 남아
   `<mask>` 안에서 늘어난다. 자세한 것은 `src/chart.js` 머리말과 CHANGELOG v0.48.0.
2. ⚠⚠ **밝기를 전제한 층이 또 뒤집혔다.** 해도는 안개를 *갈 수 있는 바다 안쪽에만* 깔아 바깥이
   **종이**다 — 미니맵의 빗금(중간 회색)과 끝선(상아색)을 그대로 쓰니 **둘 다 사라졌다.**
   5단계에서 카드·토스트를 옮길 때 **그 요소가 앉는 바탕이 종이인지 어둠인지**부터 본다.
3. **번호·순서·색·좌표의 출처는 언제나 데이터다** — 범례 번호를 지도 데이터의 키 순서로 매겼다가
   존 정보 블록과 갈라졌다 (`09 AMBER` vs `07 AMBER ZONE`). `areas.js` 에서 받는다.

### 4-1단계에서 나온 것 (v0.49.0) — 향 영역이 지도가 됐다

사용자가 지형 JSON 둘과 렌더 예시를 주었다. **향조별 영역 경계가 이미 벡터로** 들어 있어 새로 계산할
것이 없었다 (30고리 + 해안선 4고리 · `src/terrain-data.js` 는 생성물이다).

4. ⚠⚠ **미탐색 안개를 색 위에 얹지 않는다.** 향조 색은 일부러 등휘도라(불변식 21) 눌리면 아홉이
   한 회색으로 뭉치고 **채도를 빼도 못 살린다.** 너울을 색 **아래**에 깔고, 지나온 곳에 색을 한 겹 더 얹는다.
5. **안개를 타는 것은 이름뿐이다.** 영역과 점은 전부 보인다 (2026-09-11 규약). 5단계의 카드·토스트도
   같은 물음을 먼저 한다 — *이 요소가 정보인가, 보상인가.*
6. 확대를 전제하면 **모든 경계는 벡터**여야 한다. ⚠ v0.49.0 에서는 *"안개처럼 부드러워야 하는 것은 격자 그림으로"* 라고
   적었는데 **틀렸다** — 6배에서 흐린 계단이 됐다. v0.50.0 부터 해도에는 그림이 하나도 없다 (안개도 마칭 스퀘어 윤곽).
7. **무늬(빗금)는 확대에 약하다** — 결이 배율만큼 커져 지도가 아니라 천처럼 읽힌다. 뜻은 **한 색**으로 준다 (`--pb-void`).

### 5단계(카드)에서 나온 것 (v0.53.0) — 카드와 미니맵이 저녁 유리가 됐다

8. **표면 토큰을 바꾸지 않고 판마다 토큰을 새로 만들었다** (`--pb-card-*` · `--pb-mini-*`). `--pb-surface` 계열은 검색창 · 해도가 그대로 쓴다 —
   그걸 바꾸면 요청 밖의 표면까지 같이 어두워진다. 켜는 것은 시간대가 아니라 **제 스위치**(`<html data-card-eve>` · `data-mini-eve`)다.
9. ⚠⚠ **비치는 바탕은 겹친 곳이 짙어진다** — 말풍선 꼬리(45° 정사각형)가 상자와 겹친 절반이 그렇다. 바깥 삼각형만 남긴다 (clip-path).
10. **글자색의 출처가 바탕을 따라 바뀐다** — 종이 위에서는 먹 쪽으로 누른 향조색(`inkOf`), 어두운 유리 위에서는 부표 제 색을 상아색 쪽으로.
11. **훑어보는 카드와 고른 카드는 다르다** — 미리보기(호버)는 더 비치고 마우스를 통과시키고, 누른 카드는 진하고 받는다.
12. ⚠ 해도는 아직 상아색이다 — 미니맵과 해도의 '갈 수 없는 바다' 색이 갈라졌다 (미니맵 저녁 판 `#2B3038` · 해도 `--pb-void` `#515A61`). 해도를 저녁으로 옮길지는 사용자 결정.

### 5단계(토스트)에서 나온 것 (v0.56.0) — 경고가 저녁 유리 알약이 됐다

13. ⚠⚠ **한 요소가 여러 바탕에 앉으면 가장 불리한 바탕으로 진하기를 정한다.** 토스트는 검색바 밑 하늘에도, 열린 해도(상아색 종이) 위에도 뜬다 —
    카드의 0.58 을 그대로 쓰면 종이 위에서 회색 바탕에 상아색 글자가 된다. 그래서 0.80 (`--pb-warn-bg`).
14. ⚠ **해도(z-index 40)가 열린 채로 불리는 UI 는 해도보다 위에 선다.** 토스트가 30 이라 해도에서 누른 '범위 밖' 경고가 해도 밑에 깔려 있었다 (→ 45).
    새 UI 를 붙일 때 *해도가 열린 상태에서도 불리는가* 를 먼저 본다.
15. 브론즈는 레퍼런스의 쓰임 그대로 **표지와 밑줄**에만 쓴다 — 글자까지 브론즈로 칠하면 경고가 장식으로 읽힌다. 제목은 상아색이다.

## 5. 하지 않는 것

- **레퍼런스를 그대로 옮기지 않는다.** 대리석 흉상 · 콜라주 · 'ROAM' 브랜드는 이 서비스의 것이 아니다.
- **수면 타이포(title.js)를 건드리지 않는다.**
- 스타일 체계를 새로 만들지 않는다 — 인라인 + `--pb-*` 변수 그대로다 (불변식 7 · 23).
- 3D 씬의 색(물 · 하늘 · 부표)은 이 작업의 범위가 아니다. 그건 `CONFIG.times` 다 (불변식 25).
