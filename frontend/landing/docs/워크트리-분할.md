## 2. 같이 쓰는 파일 — 부딪치는 곳

| 파일 | 규칙 |
|---|---|
| `main.js` (모든 모듈 배선) | 자기 함수 · 블록 안만. 새 `import` · `createX()` · `disposeAll()` 등록 · `onResize` 등록은 **한 줄 덧붙이기만** — 기존 줄을 옮기거나 정렬하지 않는다 |
| `window.PB = { … }` (한 줄) | 갈래 브랜치에서는 **안 고친다**. 필요한 이름은 메모에 적고 통합할 때 넣는다 (한 줄이라 누가 고쳐도 반드시 충돌한다) |
| `params.js` · `PARAM_RANGES` | 자기 섹션 **끝에** 추가. 섹션 순서 · 들여쓰기를 안 바꾼다 |
| `compare.js` 의 `BASELINES` | 한 줄 덧붙이기만 |
| `times.js` · `config.js` · `util.js` | 여럿이 읽는다 — 값 추가는 되고, 기존 값 · 시그니처 변경은 메모에 요청으로 |
| `CHANGELOG.md` · `landing/CLAUDE.md` · `package` 버전 | 갈래 브랜치에서는 **안 고친다** → §3 메모에 적고 통합할 때 옮긴다 (둘 다 파일 맨 위에 쌓여서 반드시 충돌한다) |

## 3. 갈래 메모

`landing/docs/분할/A-바다.md` · `B-부표.md` · `C-연출UI.md` · `D-앱연결.md` — 갈래마다 자기 파일 하나만 쓴다.

```
## 바꾼 것        ← 나중에 CHANGELOG 항목이 된다 (버전 번호는 비워 둔다)
## 새 불변식      ← 나중에 landing/CLAUDE.md 로 옮긴다
## PB 에 넣을 이름
## 다른 갈래에 요청
## 롤백           ← 파라미터 0 이면 예전 화면인지
```
