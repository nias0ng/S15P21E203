## 1. 그림자 — 코드도 값도 안 건드려졌다

`9f862a0`(평면 반사 패스 직전)부터 HEAD 까지 **diff 0 줄**이다 :

```bash
git diff 9f862a0..HEAD -- 3D/paperboat/src/params.js | grep -E "^[+-] +(shadow|contact)"   # 출력 없음
git diff 9f862a0..HEAD -- 3D/paperboat/src/water.js  | grep -E "^[+-].*(uShadow|uContact)"  # 출력 없음
```

### ⚠ 단 하나, **간접**으로 움직인 것

`reflectRise` 를 0.55 → 0 으로 내렸는데(v0.15.5), 이 값은 **이중 용도**였다 :

```js
uni.uBoatPos.value.set(x, boatObj.position.y + P.reflectRise, z);
```

그리고 드리운 그림자가 그 `uBoatPos.y` 로 광선을 푼다 :

```glsl
float t = (uBoatPos.y - vW.y) / max(uLightDir3.y, 0.08);
```

**실측 : 그림자 무게중심이 195px 이동했고 24,837 픽셀이 달라졌다** (28,742 → 25,349px).
배 높이가 0.55 낮아진 만큼 광선 투영 거리가 짧아져서 **그림자가 배 쪽으로 당겨졌다.**

**되돌리는 법 — `params.js` 에서 한 줄 :**

```js
reflectRise: 0.55,   // 그림자를 v0.15.4 이전 자리로 되돌린다
```

⚠ 이러면 반사가 다시 제자리에서 58% 밀려난다 (v0.15.5 가 고친 것). **둘은 맞바꾸는 관계다.**
둘 다 원하면 `uBoatPos.y` 에 더하는 값과 반사용 값을 **분리**해야 한다 —
셰이더는 이미 `uBoatY`(날것)를 따로 받고 있으므로, 그림자 블록이 `uBoatPos.y` 대신
`uBoatY + (새 파라미터)` 를 쓰게 바꾸면 된다. 5분짜리다.

## 2. 그림자 값 (v0.13.4~v0.14.1 에서 사용자가 직접 잡은 것)

```js
shadowAmount: 0.35,   shadowSize: 1.55,   shadowSoft: 0.25,   shadowKnee: 0.28,
shadowOcclude: 0.90,  contactAmount: 1.00, contactSize: 1.5,  contactLift: 1.60,
boatShadow: '#6B7A92',   // config.js
```

구조 (셋을 합치지 않는다 — 불변식 0-3-2) :

| 층 | 파라미터 | 방향성 |
|---|---|---|
| 드리운 그림자 | `shadowAmount` | **광원**을 따라 눕는다 |
| 접촉 그림자 | `contactAmount` | **없는 것이 맞다** (주변 차폐) |
| 빛 가림 | `shadowOcclude` | 해는 둘 다, 하늘은 접촉만 |

감쇠는 **심 + 무릎** (`shadowSoft` 안쪽은 평평, `shadowKnee` 폭에서 0).
⚠ 예전처럼 `smoothstep(0.15, 1.0)` 을 제곱하면 꼬리가 발자국 전체에 깔려 **얼룩**이 된다.

## 5. ⚠ 반사 구간에 섞여 있는 '반사와 무관한' 수정들

되돌리면 **같이 사라진다.** 대부분 되살릴 이유가 없는 버그 수정이다.

- `reflect.js` 의 죽은 코드 (`viewProjection`·`planeN`) 제거 — 셰이더가 안 읽던 것
- 반사 합성의 `clamp` 추가 — 없으면 세기를 올릴 때 mix 가 1 을 넘어 **외삽**된다
- 부표 슬라이더 범위 (`markHeight` 하한 0.2 → −1) — 반쯤 잠그려면 0 이 필요한데 못 갔다
- 반사 시험대 (`markLayout 1`) — 규칙적 배치. 검증용이라 기본은 0 이면 된다
