## 2. 파생 4색

팔레트 7색만으로는 본문 대비 기준(4.5:1)을 못 넘기는 자리가 있습니다.
컨셉 톤 안에 머물면서 기준을 넘도록 계산한 값입니다.

| 토큰 | 값 | 대비 (ivory 위) | 산출 방식 |
| --- | --- | --- | --- |
| `charcoal-soft` | `#727170` | **4.51:1** | `charcoal` 을 `ivory` 쪽으로 33% |
| `bronze-deep` | `#7f6f4d` | **4.54:1** | `bronze` 를 `charcoal` 쪽으로 |
| `sage-deep` | `#556150` | **6.06:1** | `sage` 를 어둡게 |
| `rust` | `#8f4632` | **6.30:1** | 흙빛 러스트 (빨강 대체) |

**빨강 대신 러스트를 쓰는 것이 핵심입니다.** `#8f4632` 는 `bronze` 와 같은 흙 계열이라
화면에서 이물감이 없으면서 위험은 충분히 전달합니다. 순수 빨강은 이 팔레트 위에서
혼자 튑니다.

## 3. 대비 검증 (WCAG 2.1)

본문은 4.5:1, 큰 글씨(18px 이상 또는 14px 굵게)와 UI 요소·포커스 표시는 3:1 이 기준입니다.

### 바탕 `ivory` 위

| 전경 | 대비 | 판정 | 그래서 |
| --- | --- | --- | --- |
| `charcoal` `#2f2f32` | 12.36:1 | AAA | 본문 확정 |
| `rust` `#8f4632` | 6.30:1 | AA | 에러 문구 |
| `sage-deep` `#556150` | 6.06:1 | AA | 성공 문구 |
| `bronze-deep` `#7f6f4d` | 4.54:1 | AA | 버튼 바탕 · 포커스 링 |
| `charcoal-soft` `#727170` | 4.51:1 | AA | 보조 텍스트 |
| `sage` `#7f8a7a` | 3.34:1 | 큰 글씨·UI만 | 아이콘 · 태그 |
| `bronze` `#a68f5b` | **2.90:1** | **실패** | 글자로 못 씀 → 테두리·선 |
| `shimmer` `#a7c8db` | **1.63:1** | **실패** | 그라데이션 면으로만 |
| `stonegray` `#c9c4bb` | **1.61:1** | **실패** | 테두리 전용 |

### 바탕 `charcoal` 위

밝은 바탕에서 못 쓰던 색들이 어두운 바탕에서는 본문급으로 살아납니다.

| 전경 | 대비 | 판정 |
| --- | --- | --- |
| `ivory` | 12.36:1 | AAA |
| `bone` | 10.28:1 | AAA |
| `stonegray` | 7.69:1 | AAA |
| `shimmer` | 7.58:1 | AAA |
| `bronze` | 4.26:1 | 큰 글씨·UI만 |

> 향 지도를 어두운 바탕으로 가면 `shimmer` 를 제대로 쓸 수 있습니다.
> 컨셉아트도 지도 패널만 어둡게 갔습니다. **다만 메인 페이지는 재디자인 대기 중이라
> 이번 범위에서 제외했습니다.**

### 컨셉아트에서 고친 것

컨셉아트의 `EXPLORE DESTINATIONS` 버튼은 `bronze` 바탕에 흰 글씨인데 **2.90:1** 로
기준의 절반 수준입니다. 밝은 데서 폰으로 보면 누구든 안 보입니다.
버튼 바탕만 `bronze-deep` 으로 어둡게 잡아 4.54:1 을 맞췄고, 색감 차이는 거의 없습니다.

| `danger` | `rust` | 삭제 · 에러 |

### 두 가지 금지 규칙

- **`accent` 를 글자색으로 쓰지 않습니다** (2.90:1). 테두리·아이콘·구분선에만 씁니다.
- **`glow` 를 글자색으로 쓰지 않습니다** (1.63:1). 검색 버튼의 원형 그라데이션처럼
  **면**으로만 씁니다.

두 규칙은 코드로 강제되지 않습니다. 리뷰에서 봐야 합니다.

## 5. 활자

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `font-sans` | `Noto Sans KR` | 본문 · 라벨 · 버튼 · 입력창 |
| `font-serif` | `Noto Serif KR` | 제목 · 향수명 · 컬렉션 이름 |

실물은 `index.html` 의 `<link>` 가 받아옵니다. CSS 의 `@import` 로 넣으면 스타일시트를
받은 **뒤에야** 폰트 요청이 시작돼 글자가 늦게 뜹니다.

- `display=swap` — 폰트가 늦어도 글자는 시스템 폰트로 먼저 보입니다
- 굵기는 실제로 쓰는 것만 받습니다 — 본문 400·500·700, 제목 600·700
- 한글 폰트는 굵기 하나가 무거워서 전 범위를 받으면 초기 로딩이 눈에 띄게 느려집니다

**컨셉의 정체성은 에디토리얼 세리프입니다.** 다만 본문까지 세리프면 한글 가독성이
떨어져서 제목 전용으로 둡니다.

> 이전에는 `Pretendard` 가 **선언만 되어 있고 실제 로드가 없어** 시스템 폰트로
> 떨어졌습니다. 팀원마다 같은 화면이 다르게 보였습니다.

## 7. 컴포넌트 규칙 (161에서 확정된 것)

### Badge — tone 은 색 이름이 아니라 뜻

| tone | 표현 | 쓰는 곳 |
| --- | --- | --- |
| `neutral` | `bg-line-soft` + `text-ink-muted` | 향 계열 · 노트 — 대부분 |
| `accent` | `accent-deep` 테두리·글자 | 진열대 분류 · 보유 상태 |
| `success` | `success` 테두리·글자 | 저장 완료 |
| `danger` | `danger` 테두리·글자 | 검수 보류 · 삭제 예정 |
| `outline` | `line` 테두리 | 카드 위에 여러 개 나열 |

색 이름(`vapor`·`iris`·`coral`·`seaglass`)에서 뜻으로 바꾼 이유는, 팔레트가 또 바뀌어도
호출부를 안 고치기 위해서입니다. **색만으로 뜻을 구분하지 말고 라벨 글자도 함께 답니다.**

### Button

| variant | 표현 |
| --- | --- |
| `primary` | `bg-ink` + `text-surface`, hover `bg-ink-muted` |
| `secondary` | `bg-line-soft` + `text-ink`, hover `bg-line` |
| `outline` | `line` 테두리 + 투명 바탕 |
| `ghost` | 투명 + `text-ink-muted` |
| `danger` | `bg-danger` + `text-surface` |

- 포커스 링은 `ring-accent-deep` 입니다. `accent` 는 2.90:1 이라 포커스 표시 기준 3:1 에 못 미칩니다.
- 비활성은 **테두리만 남기기**로 확정되었습니다 (와이어프레임 A32).

> `primary` 가 아직 `charcoal` 입니다. 컨셉아트의 주요 버튼은 브론즈인데,
> 컴포넌트가 어느 토큰을 쓸지는 S15P21E203-162 명세를 거쳐 163 에서 정합니다.

### 호버 매핑 주의

기계적으로 치환하면 안 되는 자리가 있습니다. `SimilarExplorer` 의 호버는 원래
**어두워지면서 흰 글씨**가 되는 동작이라, `bg-line`(stonegray)으로 바꿨으면
흰 글씨가 1.61:1 이 됩니다. `bg-ink` 로 매핑해야 맞습니다(12.36:1).
