## 보류: C02 선택 모달 3종

**보류 이유**: 두 도메인이 함께 필요한 모달인데, 안에 들어갈 향수 검색 목록이
향수 도메인(에픽 110)에 있어야 합니다. 110 이전에 만들면 목록을 가짜로 채워야 하고
나중에 다시 씁니다.

- `향수 선택` — A24b `[+ 향수 선택]` 과 A19 `향수 추가` 에서 공용
  (와이어프레임에는 X01 `[연결할 향수 선택 ▾]` 도 적혀 있지만 X01 은 만들지 않습니다)
- 나머지 2종은 C02 아트보드 참고

**놓을 위치**: `features/a` 가 `features/b` 를 import 할 수 없으므로(ESLint 강제),
커뮤니티(114)와 컬렉션(113) 양쪽에서 쓰는 이 모달은 `shared/ui` 에 껍데기를 두고
향수 목록 데이터는 호출하는 쪽에서 넘기는 형태가 됩니다.

**처리 시점**: 에픽 110 작업 중 향수 검색이 붙은 뒤. 113 · 114 작업 전에는 있어야 합니다.

## 와이어프레임과 기능 명세서 차이

- `A34` 브랜드, `A35`·`A36` 노트는 기능 명세서에 요구사항 ID가 없는 신규 화면입니다
  (명세서는 이후 수정 예정).
- 개인화 추천(REC-12 · REC-13)은 별도 화면 없이 `A01` 향 지도의 취향 영역으로 표시합니다.
- `A04` 는 `A06` 으로 통합되었습니다. 와이어프레임 본문에 남은 `A04` 참조는 `A06` 으로 읽으세요.
