## 08/24 (월) — 요구사항 검토 및 데이터 분석 준비
* 요구사항 정의서 리뷰
  * 기존 요구사항을 검토하며 누락된 기능, 보완이 필요한 부분 및 각 요구사항의 필요성 점검
* 향수 가격 데이터 수집
  * 서비스 내 가격대 분류에 활용할 수 있는 공개 향수 가격 데이터셋 탐색 및 수집
* 팀 회의
  * 팀명 확정
  * 팀원별 역할 분담
* 자연어 쿼리 데이터 분석 준비
  * 팀 내에서 수집한 향수 관련 자연어 쿼리를 하나씩 검토
  * 자연어형/단어형 및 사용자 목적에 따른 분류 작업 시작
  * 분류 과정에서 문장별 추가 고려 요소를 발견하여 기존 분류 작업 중단
  * 일관된 데이터 분석을 위한 작성·분류 가이드 수정

## 08/25 (화) — 사용자 흐름 및 기능 명세 고도화
* 기능 명세서 기준 사용자 흐름 검토 및 회의 진행
* 주요 기능 진입 경로와 사용 Depth를 점검하고, 사용자가 기능 목적을 이해하기 어려운 부분 및 불필요하게 복잡한 흐름 검토
* 후기·시향 기록·평점 등 유사 기능 간 역할과 목적 구분 논의
* 향수 검색, 시향 기록, 이미지 생성 등 핵심 기능의 연결 흐름 및 접근 방식 재검토
* 유사 향수 탐색, 추천 기능 등 중복되거나 통합 가능한 기능 정리
* 향수 검색 기능 및 게시글 내용 필터링 기능 신규 추가 및 상세 흐름 정의
* 게시글 작성·수정 시 부적절한 표현 및 커뮤니티 주제 관련성을 검사하는 게시 전 필터링 정책 구체화
* 개인화 추천과 자연어 추천의 향 지도 활용 방식 분리

  * 개인화 추천 향수는 랜딩 페이지의 향 지도에 기본 표시
  * 자연어 입력 시 추천 결과가 위치한 향 영역으로 지도가 자동 이동하도록 흐름 구체화
* 기능 명세서 기준으로 기존 요구사항의 삭제·통합·흡수 관계 정리
* 회의 및 기능 명세 변경 사항을 반영하여 요구사항 정의서의 기능명, 상세 설명 및 정책 수정
* 사용자 관점에서 기능 단위를 재정리하고, 중복·내부 로직·단순 화면 이동 등을 기준으로 기능 명세서 최종 수정

## 08/26 (수) — 사용자 조사 설계 및 커뮤니티·데이터 소스 조사
### 사용자 설문 설계
* 향수 추천 관련 사용자 설문 목적 및 문항 재검토
* 기존 설문 문항의 범위가 지나치게 넓은 문제 확인
* 일반 사용자가 실제로 향수를 추천받을 때 사용하는 자연어 표현과 주요 추천 조건을 수집하는 방향으로 설문 목적 구체화

### 커뮤니티 레퍼런스 조사
* 향수 커뮤니티 구조 설계를 위한 국내·외 커뮤니티 레퍼런스 조사
* 한국·일본·중국·영미권의 주요 웹 커뮤니티 및 향수 전문 커뮤니티 조사
* 디자인보다는 게시판 구성, 정보 분류, 사용자 참여 방식 등 커뮤니티 구조 중심으로 레퍼런스 분석
* 서비스 내부에 단일 향수 게시판을 운영하는 경우 참고할 커뮤니티 기능 및 콘텐츠 구조 검토

### 향수 데이터 소스 조사
* 향수 데이터 확보를 위한 외부 데이터 소스 조사
* Kaggle, GitHub, OpenBeautyFacts 등 공개 향수 데이터셋 및 API 조사
* 각 데이터 소스에서 제공하는 향수명, 브랜드, 가격, 향조 등 데이터 항목 및 활용 가능성 비교
* Basenotes의 향수 DB 구조 및 CSV/API 형태의 데이터 활용 가능 여부 확인
* 향수 추천 및 검색 기능에 활용 가능한 데이터 소스 후보 정리
