## 1. SSAFY GMS (LLM 게이트웨이)

### 1-1. 무엇인가

SSAFY 가 제공하는 **OpenAI 호환 프록시**입니다. 요청·응답 형식이 `/chat/completions`
규격 그대로이고 인증만 GMS 키로 바뀝니다. **OpenAI 계정은 따로 필요 없습니다.**

### 1-2. 가입·발급

| | |
|---|---|
| 발급처 | SSAFY GMS 포털 |
| 발급받는 것 | **GMS API 키 1개** |
| 만료 시 | HTTP 401 `Invalid or expired GMS key` — **재시도로 풀리지 않습니다.** 포털에서 재발급 |
| 엔드포인트 | `https://gms.ssafy.io/gmsapi/api.openai.com/v1/chat/completions` |

**키 하나를 AI 서버와 백엔드가 함께 씁니다.**

### 1-3. 호출하는 곳이 둘입니다

#### (가) AI 서버 — 자연어 추천

| | |
|---|---|
| 파일 | `ai/llm_stage1.py` (호출 본체) · `ai/server.py` (상태 로깅) |
| 모델 | `gpt-5.4-nano` (기본값) |
| 쓰는 곳 | 1단계 문장 구조화 · 5단계 미매칭 표현 accord 추정 |
| 환경변수 | `GMS_API_KEY` · `GMS_MODEL` · `GMS_ENDPOINT` |

⚠ **키가 없어도 서버는 정상 기동합니다.** 사전 매칭만 쓰는 상태로 내려가고,
조건을 뽑는 비율이 **88.8% → 76.8%** 로 떨어집니다. 에러가 안 나므로
`/health` 의 `"llm"` 칸이나 기동 로그로 확인해야 합니다.

```bash
curl http://localhost:8000/health
# {"status":"ok","perfumes":129161,"accords":92,"llm":true}
```

#### (나) 백엔드 — 향수 후기 요약 배치

| | |
|---|---|
| 파일 | `backend/.../perfume/client/GmsReviewAnalyzer.java` |
| 설정 | `backend/.../perfume/batch/ReviewAnalysisProperties.java` |
| 모델 | `gpt-5-nano` (기본값) |
| 인증 | `Authorization: Bearer <GMS 키>` |
| 환경변수 | `REVIEW_ANALYSIS_ENABLED` · `GMS_API_KEY` · `GMS_MODEL` · `REVIEW_ANALYSIS_CRON` |
| 문서 | `backend/docs/review-analysis-batch.md` |

⚠ **`REVIEW_ANALYSIS_ENABLED=true` 인데 키가 없으면 애플리케이션 기동이 실패합니다.**
의도된 동작입니다 — 조용히 안 도는 것보다 낫다는 판단입니다.

### 1-4. ⚠ 모델 변수 이름이 어긋납니다

루트 `.env` 는 `NLR_GMS_MODEL`(AI) · `BACKEND_GMS_MODEL`(백엔드) 로 나눠 두었는데
**코드는 양쪽 다 `GMS_MODEL` 을 읽습니다.** `compose` 가 옮겨 주므로 **도커에서만 맞습니다.**

```yaml
# compose.manual-test.yaml
ai:
  environment:
    GMS_MODEL: ${NLR_GMS_MODEL:-gpt-5.4-nano}
backend:
  environment:
    GMS_MODEL: ${BACKEND_GMS_MODEL:-gpt-5-nano}
```

AI 서버를 `uvicorn` 으로 직접 띄우면 `NLR_GMS_MODEL` 이 무효이고 기본값으로 돕니다.

## 2. AWS S3 + CloudFront (이미지 저장·배포)

### 2-1. 무엇인가

사용자가 올린 이미지를 S3 에 저장하고 **CloudFront 를 통해서만** 내보냅니다.
버킷은 CloudFront 만 읽도록 잠겨 있습니다.

**기본값은 꺼져 있습니다**(`IMAGE_STORAGE_S3_ENABLED=false`). 끄면 서버 디스크에 저장합니다.

### 2-2. 가입·발급

| 필요한 것 | 비고 |
|---|---|
| AWS 계정 | |
| **S3 버킷** | 리전 예: `ap-northeast-2` |
| **CloudFront 배포** | 오리진을 S3 버킷으로. 공개 주소가 `IMAGE_STORAGE_S3_PUBLIC_BASE_URL` |
| **IAM 자격 증명** | 액세스 키 2종, 또는 **EC2 인스턴스 역할로 대체 가능** |

### 2-3. 환경변수

| 변수 | Spring 프로퍼티 | 용도 |
|---|---|---|
| `IMAGE_STORAGE_S3_ENABLED` | `hyanghae.storage.s3.enabled` | on/off. 기본 `false` |
| `IMAGE_STORAGE_S3_BUCKET` | `...s3.bucket` | 버킷 이름 |
| `IMAGE_STORAGE_S3_REGION` | `...s3.region` | 리전 |
| `IMAGE_STORAGE_S3_PUBLIC_BASE_URL` | `...s3.public-base-url` | **CloudFront 주소** (S3 직접 주소가 아님) |
| `IMAGE_STORAGE_S3_KEY_PREFIX` | `...s3.key-prefix` | 개발·운영 경로 분리 (`uploads/dev` 등) |
| `IMAGE_STORAGE_S3_PUBLIC_PATH_PREFIX` | `...s3.public-path-prefix` | CloudFront 오리진 경로 중복 회피 |
| `AWS_ACCESS_KEY_ID` | (AWS SDK 가 직접 읽음) | 자격 증명 |
| `AWS_SECRET_ACCESS_KEY` | | |
| `AWS_SESSION_TOKEN` | | 임시 자격 증명일 때만 |

### 2-4. 구현 위치

```
backend/src/main/java/com/hyanghae/backend/global/storage/
  S3ClientProvider.java · S3ImageStorage.java
  ImageStorageProperties.java · ImageStorageFactory.java
```

인계 문서 — `backend/docs/image-upload-s3-handover.md` · `backend/docs/image-upload.md`

### 2-5. ⚠ CloudFront 도메인이 프론트에 하드코딩돼 있습니다

향수 이미지 주소가 프론트 파일에 직접 박혀 있습니다.

```
frontend/landing/src/perfumes-data.js   향수 이미지 200여 건
frontend/mock/api.ts                    목 데이터용 CDN 상수
```

**CloudFront 도메인이 바뀌면 이 파일들도 같이 고쳐야 합니다.**

## 4. 사용하지 않는 외부 서비스

제출 양식의 예시 항목에 대한 답입니다.

| 항목 | 사용 여부 | 근거 |
|---|---|---|
| **소셜 인증** (카카오·네이버·구글) | **사용 안 함** | 자체 이메일·비밀번호 계정입니다. 백엔드의 `oauth2` 코드는 **자체 발급 JWT 를 검증하는 Spring Security 클래스**이고 소셜 로그인이 아닙니다 |
| **포톤 클라우드** | 사용 안 함 | 실시간 멀티플레이 기능이 없습니다 |
| **코드 컴파일 서비스** | 사용 안 함 | |
| **지도 API** | 사용 안 함 | 「향 지도」는 three.js 로 직접 그리는 자체 3D 화면입니다 |
| **결제** | 사용 안 함 | |
| **알림·푸시·SMS** | 사용 안 함 | |
| **메일(SMTP·SendGrid)** | 사용 안 함 | |
| **외부 모니터링 SaaS** | 사용 안 함 | 자체 호스팅 Prometheus 를 전제로 `actuator` 에 `health`·`prometheus` 만 엽니다 |

### 인증 방식 (참고)

```
POST /auth/signup            회원가입
POST /auth/login             로그인 -> accessToken (자체 발급 JWT)
GET  /users/me               내 정보
PATCH /users/me/password     비밀번호 변경
DELETE /users/me             탈퇴
```

서명 키는 `JWT_SECRET` 이고 **외부 서비스가 아닙니다.** 운영에서 미설정 시 기동이 실패합니다.

## 5. 새 환경에서 준비해야 할 것 — 체크리스트

```
[ ] SSAFY GMS 포털에서 API 키 발급            -> GMS_API_KEY
[ ] JWT_SECRET 생성 (충분히 긴 무작위 문자열)   -> 운영 필수
[ ] 이미지 저장을 S3 로 쓸 것인가 결정
      예 -> AWS 계정 · S3 버킷 · CloudFront 배포 · IAM 자격 증명
      아니오 -> IMAGE_STORAGE_S3_ENABLED=false 로 두고 업로드 볼륨만 연결
[ ] 후기 요약 배치를 켤 것인가 결정
      예 -> REVIEW_ANALYSIS_ENABLED=true (GMS_API_KEY 가 반드시 있어야 함)
[ ] 폐쇄망이면 웹폰트를 로컬로 내려받아 번들할지 검토
```
